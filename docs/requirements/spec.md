# nova 需求规格

> 版本：v4.0
> 状态：**基线**（参数见 [`parameters.md`](./parameters.md)）
> 范围：对齐 OpenAI Responses 协议封闭子集的生成服务——创建生成、流式订阅与精确续订、服务端上下文寻回。
> 边界依据：[`../architecture/decisions.md`](../architecture/decisions.md) D20 / D21 / D22 / D25

---

## 1. 系统目标

构建一个 **单次生成（Response）流式服务**：调用方创建一次生成，可同步等待、同连接流式接收，或后台创建后另行订阅；执行过程的增量事件可被精确续订。服务端存储该次生成的输入输出条目，使后续轮次仅凭上一次生成的标识即可寻回历史，无需重传全部对话。

对外主资源是 **单次生成**，不是跨轮次的会话线程。核心命题为 **存储与订阅分离**：服务持有生成内容用于按需拼接上下文，但不提供会话线程级的流式订阅与开屏还原。

### 1.1 角色

| 角色 | 描述 | 主要关注 |
|------|------|---------|
| **调用方** | 创建生成的合作方服务或应用 | 创建成功、协议契约稳定、多轮上下文可寻回 |
| **订阅者** | 接收某次生成流式事件的连接 | 无重无漏、断线可精确续订 |
| **执行端** | 领取生成并写入事件、终态提交输出条目 | 领到生成、写入被 fence 保护 |
| **运维** | 系统运营方 | 扩缩容、故障处置、保留期治理 |

### 1.2 术语

| 术语 | 定义 |
|------|------|
| **生成**（Response） | 一次模型调用的完整生命周期与其结果对象；对外唯一主资源 |
| **条目**（Item） | 生成的输入或输出单元（消息、函数调用、函数调用结果）；协议封闭子集的成员 |
| **事件流** | 一次生成执行期间产生的增量事件序列，序号为该次生成内 **0 基连续**的 `sequence_number` |
| **在途事件缓冲** | 承载事件流的共享中间件（具体方案后置：Redis Streams / TDMQ 等）；生命周期为生成时长 + 保留窗口，**不持久化** |
| **上下文库** | 持久化存储生成条目的组件，支撑上下文快照的固化与读取 |
| **上下文链** | 由 `previous_response_id` 元数据连成的生成序列；每个生成**物化**其创建时可见的完整历史（D24），读取即读快照 |
| **账本** | 生成的状态、归属、幂等键、用量记录；与上下文库同库同事务 |
| **尝试序号**（Attempt） | 生成被领取的次数，每次领取递增；用于隔离失效持有者的写入 |
| **订阅游标** | 调用方持有的 `(response_id, sequence_number)`，用于断线后精确续订 |
| **共享事件缓冲** | 承载所有生成在途事件的共享中间件；任一接入节点均可读取与订阅 |
| **协议封闭子集** | 对外支持的协议范围；超出即明确拒绝（见 [`../design/06-protocol-subset.md`](../design/06-protocol-subset.md)） |

> **不在术语表内**：调用方为渲染而维护的完整事件历史（transcript）不是本服务的概念——服务既不定义它，也不存储它，更不在任何代码路径上判断它。它由调用方从实时事件流自行构建并持有。

### 1.3 需求书写约定

1. 描述可观察的外部行为与必须成立的性质，不指定实现方式。
2. 每条需求配可测验收标准。
3. 类别：**功能 FR** / **正确性 CR** / **质量 SR·OR** / **安全 SEC**。

## 2. 功能需求（FR）

### 2.1 生成生命周期

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-1** | 任意接入节点均可创建生成，节点对等无主从 | 任意节点创建，成功率与延迟无显著差异（P99 延迟差 < 200ms） |
| **FR-2** | 创建支持三种响应模式：同步等待、同连接流式、后台创建 | 后台模式立即返回生成对象；同步模式在超时内返回终态对象，超时返回当前状态对象供轮询 |
| **FR-3** | 创建幂等：同一幂等键重复到达只产生一个生成 | 同一幂等键重放多次 → 仅 1 个生成 |
| **FR-4** | 生成由**独立执行进程**领取并执行 | 执行端经账本端口全局领取待执行生成；取用为原子转换且 attempt 递增；并发领取不双领（CR-1） |
| **FR-5** | 超过执行上界或执行端重启后，在途生成被回收并**明确失败** | 抬高 attempt 后原持有者写入失败；执行端重启后其在途生成转为失败态，**已完成历史不受影响** |
| **FR-6** | 过期 attempt 的写入被拒绝 | 回收抬高 attempt 后，旧持有者追加事件失败 |
| **FR-7** | 在途生成可被取消 | 取消后进入终态，发出失败事件，并记录该 attempt 的部分用量 |
| **FR-8** | 可查询生成的完整对象 | 返回状态、输出条目、用量、指令回显 |

### 2.2 流式订阅与续订

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-9** | 单次生成的事件流可被订阅 | 订阅可获得该次生成自起点起的全部可用事件 + 后续增量 |
| **FR-10** | 订阅中断后可按序号精确续订 | 带 `starting_after` 或 `Last-Event-ID` 重连，**无重复无遗漏** |
| **FR-11** | 调用方唯一需持久化的连接级状态是游标 `(response_id, sequence_number)` | 换连接、换设备可续订；服务端无连接粘性 |
| **FR-12** | 请求位点已被驱逐或超出保留窗口时必须明确报错 | 返回 410；**不返回部分数据、不静默从其它位点续发、不提供恢复路径** |
| **FR-13** | 生成标识未知或不属于该租户时返回不存在 | 返回 404（不区分二者，避免标识枚举） |
| **FR-14** | 订阅可由任意节点接入，事件序列一致 | 任意接入节点订阅均可获得一致的事件序列，无需定向转发 |

> **本服务不提供跨生成的订阅**：订阅范围永远是单次生成（D20 ⑤）。

### 2.3 存储与上下文

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-15** | 提供存储开关，**默认开启** | 开启时输入输出条目被持久化；关闭时不持久化 |
| **FR-16** | 可凭上一次生成的标识寻回历史上下文 | 携带 `previous_response_id` 创建时，服务端拼接完整历史条目交付模型，调用方只需提交新输入 |
| **FR-17** | 上下文链设深度与体积上限，**超限明确报错** | 超限返回可诊断错误；**禁止静默截断** |
| **FR-18** | 前驱不可用时必须显式报错，不得静默降级为单轮 | 四类断裂（前驱缺失或已过期、被引用者未开启存储、被引用者跨租户、超限）在**创建时**各有明确错误码 |
| **FR-19** | 指令字段不跨轮继承 | 上一轮的指令不出现在本轮拼接结果中；本轮指令仅按本次生成存储供查询回显 |
| **FR-20** | 输出条目由执行端在终态直接提交 | 存储内容与事件流为独立写入路径；**输出条目不由事件流回放派生** |
| **FR-21** | 可删除单次生成的已存内容，并支持租户级批量清除 | 删除后该生成不可再被引用为上一环；批量清除后该租户内容全部不可读 |
| **FR-22** | 已存内容到期自动清理 | 超过保留期的记录被回收并计入指标 |

### 2.4 协议子集与拒绝

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-23** | 对外协议为官方协议的封闭子集，范围可发布 | 子集规范随服务交付；声明所依据的上游规范版本 |
| **FR-24** | 未知请求字段一律拒绝 | 返回 400 并指明字段名；不静默忽略 |
| **FR-25** | 子集外的条目类型一律拒绝 | 条目引用、推理项、程序执行、计算机操作、托管工具均返回 400 |
| **FR-26** | 子集外的内容片段一律拒绝 | 内联二进制返回 400；图片与文件仅接受标识或链接引用 |
| **FR-27** | 请求体规模受限 | 条目数、单条长度、总字节、嵌套深度超限返回 400 |
| **FR-28** | 输出条目类型必须落在可接受的输入条目类型集合内 | 任一次生成的输出条目可原样作为下一次生成的输入被接受 |

### 2.5 接入与路由

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-29** | 对外单一 API 门面 | 创建、查询、订阅、取消、删除均经同一 API 契约 |
| **FR-30** | 在途事件经共享缓冲，任意接入节点可直读 | 任意节点订阅均可获得一致的事件序列，无需按生成标识定向转发 |
| **FR-31** | 上下文库为共享存储时，任意节点直连访问 | 共享时不发生节点间转发，且链亲和路由失效 |
| **FR-32** | 接入多实例无粘性 | 停一个接入实例后，调用方用同一游标换实例续订成功（在途缓冲共享的前提下） |
| **FR-33** | 超出承载时拒绝新建并明确告知 | 待领取或在途量达阈值时返回可重试拒绝；已接受的不受影响 |

### 2.6 可靠性与降级

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-34** | 优雅停机不损失在途生成 | 收到停机信号后拒绝新建、等待在途完成再退出；查询与订阅在此期间继续可用 |
| **FR-35** | 失联的执行中生成由 reap 心跳收口 | 心跳超时或执行 deadline 过期后，抬 fence 并置失败 |
| **FR-36** | 中途作废的生成须记录部分用量 | 作废后用量记录非空，计费不丢 |
| **FR-37** | 上下文库不可用时拒绝写入 | 开启存储的创建请求返回 503；**绝不降级为静默不存** |
| **FR-38** | 故障语义分层可观测 | 已完成生成不受节点故障影响；在途生成明确失败可重试，**历史完好** |
| **FR-39** | 内容完整性可校验 | 写入时计算校验值，读取时比对，不匹配返回明确错误并计入指标 |

### 2.7 会话容器（兼容层，D27）

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-40** | 提供官方会话容器的四个操作：创建、读取、更新标签、删除 | 官方 SDK 可直接驱动；更新用 POST 同路径而非 PATCH；标签整体替换，键可被移除；删除**不级联**删除响应记录 |
| **FR-41** | 生成请求可携带会话标识以继承该会话的完整历史 | 携带同一会话标识的后续生成自动继承此前全部条目；与「上一次生成标识」两种串联方式并存且互斥（同时提供返回 400）；容器不存在时**明确报错**，绝不静默降级为空上下文 |

### 2.8 会话事件流（自研层，D26）

| ID | 需求 | 验收标准 |
|----|------|---------|
| **FR-42** | 提供会话生命周期：创建（可绑定既有容器）、读取、删除 | 一个容器至多属于一个会话（绑定互斥，冲突返回 409）；删除会话不销毁其容器 |
| **FR-43** | 会话提供一条持久、严格有序、可多端订阅的事件流 | 从任意游标订阅先回放持久历史再转实时推送，单次调用完成；多个订阅者独立投递；业务自定义事件与轮次事件同处一个序号空间严格保序；业务事件**不进入模型上下文** |
| **FR-44** | 同一会话同时只允许一个进行中轮次 | 冲突方收到 409 并**被告知当前持有者**；被拒轮次不写任何事件、不留半状态；所有终态路径（完成、失败、不完整、取消、回收）都释放占用 |
| **FR-45** | 可一次取回会话的完整对话历史用于重开页面 | 单次调用返回全部条目，不要求调用方分页；与事件流合起来即可恢复界面 |

## 3. 正确性需求（CR）

| ID | 性质 | 验收标准 | 违反后果 |
|----|------|---------|---------|
| **CR-1** | **不双领**：同一生成同一时刻只被一个执行端持有 | 多执行端并发抢领，无双领 | 重复执行、输出交织 |
| **CR-2** | **创建幂等**：同一意图只产生一个生成 | 幂等键重放（含间隔后）→ 仅 1 个 | 重复计费 / 重复生成 |
| **CR-3** | **输出不交织**：被回收执行端的后续输出不得与新 attempt 混合 | 强杀后重派，订阅端无交织 | 内容错乱 |
| **CR-4** | **订阅无重无漏** | 随机断连多次，与不断连对照组一致 | 内容错乱难排查 |
| **CR-5** | **序号连续**：单次生成内序号 0 基连续无跳号 | 全量收集事件，序号恰为 `0..n` | `starting_after` 语义失效 |
| **CR-6** | **生成不丢失**：已返回成功的生成最终必达终态 | 注入故障，无永久非终态 | 任务凭空消失 |
| **CR-7** | **执行权失效后隔离**：旧 attempt 写入被拒 | 假死恢复后的写入无效 | 覆盖新结果 |
| **CR-8** | **过载不导致数据损坏** | 高压拒绝时无双领、无丢生成、无序号分叉 | 过载连带故障 |
| **CR-9** | **上下文拼接确定性且不跨租户** | 同一链多次拼接结果一致且按时间正序；链中任一环跨租户即中断报错 | 上下文漂移；跨租户泄露 |
| **CR-10** | **内容不静默丢失**：容量触顶、链断裂、库不可用一律显式拒绝 | 各故障注入均返回明确错误，无静默成功 | 后续轮次无声失忆 |
| **CR-11** | **用量不丢**：包括中途作废的部分用量 | 作废场景用量记录非空 | 计费对不上账 |
| **CR-12** | **链闭合性**：输出条目类型 ⊆ 可接受的输入条目类型 | 输出条目原样作为输入提交被接受 | 自家上下文链断裂 |
| **CR-13** | **完整性可检测**：存储层篡改可被发现 | 篡改存储内容后读取返回完整性错误 | 篡改无声生效 |
| **CR-14** | **占用与广播原子**：取得轮次占用与宣告该轮次的事件同时生效或同时不生效 | 并发抢占：恰好一个成功；被拒者不留事件；不存在「已占用但流上无事件」或反之 | 各端界面与服务端状态永久分歧，外部无法修复 |
| **CR-15** | **占用必被释放**：任一终态路径都释放轮次占用 | 完成、失败、不完整、取消、回收五条路径逐一验证释放；重复释放不重复追加事件 | 会话永久锁死，用户再也无法发言 |
| **CR-16** | **会话序号连续**：单会话内序号 0 基连续无跳号，并发下无重号 | 并发追加后序号恰为 `0..n` 且互不相同 | 游标续订失效，事件被静默覆盖 |

## 4. 质量需求

### 4.1 规模与伸缩（SR）

| ID | 需求 | 验收标准 |
|----|------|---------|
| **SR-1** | 接入可水平扩容，无连接粘性 | 实例数增加，吞吐近线性 |
| **SR-2** | 支持分钟～小时级长生成 | 长生成不被误判超时（在上界内） |
| **SR-3** | 上下文读取延迟有上界 | 读取为单次快照读取（O(1)），不受链长影响（D24） |
| **SR-4** | 在途事件缓冲容量有界 | 单次生成事件数达上限时明确拒绝，不无界增长 |

### 4.2 运维（OR）

| ID | 需求 | 验收标准 |
|----|------|---------|
| **OR-1** | 组件故障可恢复 | 接入、执行端、存储单点故障有恢复路径 |
| **OR-2** | 降级状态对调用方可见 | 不静默呈现陈旧数据、不静默跳过存储 |
| **OR-3** | 关键不变量有监控 | 双领、丢生成、位点过期、完整性失配、链断裂、孤儿收口有指标 |
| **OR-4** | 规模逼近适用区间上限时提前告警 | `parameters.md` 各维度有阈值告警 |
| **OR-5** | 保留期与删除能力可配置 | 保留期、是否校验完整性、清理节奏均为配置项，不硬编码策略 |

### 4.3 安全（SEC）

| ID | 需求 | 验收标准 |
|----|------|---------|
| **SEC-1** | 身份认证 | 未认证请求被拒绝 |
| **SEC-2** | 租户归属校验 | 查询、订阅、取消、删除均校验归属；不匹配返回**不存在而非禁止访问** |
| **SEC-3** | 快照固化时校验租户 | 创建时解析 `previous` 即校验租户，跨租户即中断并报错，不跳过继续 |
| **SEC-4** | 密钥仅从环境变量读取 | 校验密钥、数据库连接串、接口密钥不出现在配置文件与日志中 |
| **SEC-5** | 无节点间转发（原「转发目标白名单」随转发子系统移除） | 不存在由请求字段或标识推导转发地址的路径——结构上无 SSRF 向量 |
| **SEC-6** | 引用链接防护 | 仅允许 https；解析后拒绝内网地址段 |
| **SEC-7** | 请求体限制 | 条目数、单条长度、总字节、嵌套深度均有上限 |
| **SEC-8** | 数据访问参数化 | 一律参数绑定，禁止拼接查询语句 |
| **SEC-9** | 日志脱敏 | 禁止记录输入输出原文、密钥、数据库凭据 |
| **SEC-10** | 防滥用 | 单租户连接数与创建限流 |

> **归属边界**：文件标识的归属校验由文件服务负责，**不在本服务边界内**。本服务只校验链上各环的租户归属。

## 5. 需求冲突与取舍

| # | 冲突 | 仲裁 |
|---|------|------|
| **X1** | 在途事件保留成本 × 可续订性 | 有界环 + 保留窗口；位点过期明确报错且**无恢复路径**（订阅是瞬态能力，非历史查阅） |
| **X2** | 存储对话内容 × 合规删除权 | 存内容但保留期与删除接口可配置；不硬编码合规策略 |
| **X3** | 上下文读取延迟 × 存储量 × 删除后对话连续性 | 选**全量物化**（D24）：写 O(链长) 固化快照、读 O(1)、删除 O(1)；换得删除中间环后对话仍可继续 |
| **X4** | 协议兼容面 × 实现成本与安全 | 封闭子集 + 严格拒绝；发布子集规范承接兼容性诉求 |
| **X5** | 在途高可用 × 成本与延迟 | 分层投入：上下文库与账本上真库；在途共享中间件（方案后置）+ 四项缓解 |
| **X6** | 创建延迟 × 持久化 | 返回成功前必须已进入可领取持久状态；开启存储时内容写入也在此之前 |

## 6. 本期范围界定

| # | 议题 | 本期 | 说明 |
|---|------|------|------|
| **S1** | 开屏还原（渲染快照） | **不做** | 主资源为单次生成，无会话开屏概念（D20 ⑥） |
| **S2** | 会话线程级订阅 | **不做** | 订阅范围止于单次生成（D20 ⑤） |
| **S3** | 完整事件历史持久化 | **不做** | 在途缓冲瞬态；transcript 由调用方自持（D20 ④） |
| **S4** | 跨节点在途续订 | **做**（D25） | 在途缓冲共享化后，任意接入节点可续订在途事件 |
| **S5** | 跨地域灾备 | **不做** | 同城多可用区 + 备份（D21 ③） |
| **S6** | 三层高可用（在途上共享中间件） | **做**（D25 已触发，实现后置） | 选共享中间件（Redis Streams / TDMQ 等，方案待定）；依据 D25，选型见 D21 |
| **S7** | 条目引用 / 推理项 / 内联二进制 | **不支持** | 协议子集外（D22） |
| **S8** | 并行生成于同一链 | **不做** | 链为线性；分叉能力未定义 |
| **S9** | token 精确计量 | **不做** | 上下文预算用字节上限；精确计量属模型适配层 |

## 7. 验收总览

落地以分层验证为准（见 [`../design/02-verification.md`](../design/02-verification.md)）：`just verify`（全量；可指定 `l0|l1|l2|l3`）+ 人工 `just sim`。

| 类别 | 重点场景 |
|------|---------|
| 三种响应模式 | 同步等待 / 同连接流式 / 后台创建后订阅 |
| 续订 | `starting_after` 断线重连无重无漏；位点过期 410 |
| 上下文链 | 多轮拼接正序；深度与字节超限报错；四类断裂显式；指令不继承 |
| 协议子集 | 未知字段 / 条目引用 / 内联二进制 / 内网链接一律 400 |
| 链闭合性 | 输出条目原样作为输入被接受 |
| fence | 杀执行端 → 回收 → 旧 attempt 被拒 |
| 路由 | 在途共享直读；共享库时直连且链亲和退役 |
| 可靠性 | 优雅停机无损；启动孤儿收口；部分用量入账；库不可用拒写 |
| 访问控制 | 跨租户查询与走链均拒绝；越权返回不存在 |
| 完整性 | 篡改存储内容后读取报错 |
