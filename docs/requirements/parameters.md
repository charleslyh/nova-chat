# 量化参数与容量模型

> 版本：v2.0
> 配套：[`spec.md`](./spec.md)
> 本文与 `spec.md` 分离：需求相对稳定，参数需随实测校准。

---

## 1. 参数体系

| 层 | 性质 | 校准方式 |
|----|------|---------|
| ① 业务锚点 | 独立估计，可观测 | 上线后以实测校准 |
| ② 守恒关系 | 物理约束 | 无需校准 |
| ③ 导出量 | 由 ①② 计算 | 锚点变更后重算 |
| ④ SLO | 业务承诺 | 按业务调整 |
| ⑤ 适用区间 | 导出量的数倍 | 锚点变更后重评 |

> 数值为规划推导，非实测。设计须适用区间覆盖推导值数倍。

---

## 2. 业务锚点

| # | 锚点 | 取值 | 说明 |
|---|------|------|------|
| **A1** | 日活用户（DAU） | 10 万～50 万（设计取 50 万） | 业务预估 |
| **A2** | 人均日 Turn 数 | **3** | 优先校准 |
| **A3** | 平均 Turn 时长 | **≈ 8 min**（Agent 对话主导；可校准） | 影响并发 Session/Turn |
| **A4** | 日峰谷比 | **4** | 峰值 = 稳态 × 峰谷比 |
| **A5** | 同 Session 同时订阅者 | **≤ 5**（预期） | 不做分层扇出 |
| **A6** | 活跃 Turn 事件速率 | **≈ 10 条/s**（TextDelta 等，聚合后） | 优先校准 |

---

## 3. 守恒关系

| # | 关系 | 含义 |
|---|------|------|
| **B1** | 稳态：提交速率 ≈ 完成速率 | 否则 pending 无界或空转 |
| **B2** | 并发在途 Turn ≈ 提交速率 × 平均时长 | Little's Law |
| **B3** | 输出事件速率 ≈ 并发在途 × 单 Turn 事件速率 | 决定 stream 承载 |

---

## 4. 导出量（DAU 50 万设计基准）

| 参数 | 推导 | 取值 |
|------|------|------|
| 日 Turn 量 | A1 × A2 | **150 万/天** |
| 稳态提交速率 | 日量 ÷ 86400 | **≈ 17.4/s** |
| 峰值提交速率 | 稳态 × A4 | **≈ 70/s** |
| 稳态并发在途 Turn | 提交 × A3 | **≈ 1.4 万**（17.4 × 8×60） |
| 输出事件速率 | 并发 × A6 | **≈ 1.4 万～数万条/s 量级**（取规划 **~2 万条/s**） |
| 并发观测长连接 | 在线盯看用户 × 每用户 Session 数 | **约 3 万**（同前规划量级） |
| 同 Session 平均观察者 | — | **~1–2**；P99 **20**；上界 **200** |

### 4.1 路径分离（D11）的数量级依据

| 路径 | 吞吐 | 一致性 |
|------|------|--------|
| meta（Session 锁 / Turn claim） | **~70/s** 量级 | 强一致 CAS |
| stream（Session 事件 append） | **~2 万条/s** 量级 | 保序可回放 |

二者相差约 **3 个数量级**。**必须分承载**；这与 HTTP POST/SSE 是否同进程无关。

### 4.2 接入进程

一期 **POST 与 SSE 同进程**（`nova-sessions`）。3 万连接靠同质水平扩展；拆读写 Deployment 为实测触发选项。

## 5. SLO

### 5.1 延迟

| 参数 | 取值 |
|------|------|
| Turn 提交（不含生成）P99 | **< 300ms** |
| 快照开屏 P99 | **< 500ms**，且不随 Session 已时长增长 |
| SSE 首事件（热层命中）P99 | **< 200ms**（相对请求） |

### 5.2 故障与上界

| 参数 | 取值 |
|------|------|
| Agent 失联判定 | **90s**（心跳 30s × 3） |
| 回收时限 | **≤ 3 min** |
| Turn 执行时长上界 | **默认 1h**（可配置） |
| 可用性目标 | **99.9%** |

### 5.3 保留

| 参数 | 取值 |
|------|------|
| 热层窗口 | 按成本配置；卸载到冷层 |
| 有效 Session | **始终可订**（快照/冷层） |
| 区域数 / 跨区 RTT | **2～3** / **< 200ms** |

### 5.4 限额

| 参数 | 取值 |
|------|------|
| 单用户提交限流 | **10/分钟**，突发 20 |
| 单用户并发 SSE | **20** |
| 同 Session 同时订阅预期 | **≤ 5** |

---

## 6. 适用区间与越界

| 维度 | 设计基准 | 适用区间 | 越界后 |
|------|----------|----------|--------|
| DAU | 50 万 | < 300 万 | 各维度同步 |
| 峰值提交 | 70/s | < 1000/s | 提交路径批量化 |
| 输出事件速率 | ~2 万/s | < 50 万/s | 聚合窗口 / 分片流 |
| 并发 SSE | 3 万 | < 30 万 | 接入分层或拆订面进程 |
| 平均 Turn 时长 | 8 min | > 10s | **< 1s 时流式层价值下降** |

---

## 7. 校准

优先校准：A2、A3、A6、并发 SSE 实测。锚点变 → 重算 §4 → 核对 §6。
