# 任务类型画像

> 版本：v1.0 · 状态：基线（质性描述）
> 配套：[`parameters.md`](./parameters.md)（**数值以 parameters 为准**）· [`spec.md`](./spec.md)
> 决策约束：任务类型**不进入**核心流程分支（见 `decisions.md` D16）；匹配仍由受限 DSL 表达（FR-2.6 / OR-4）。

本文给出三类任务的**质性画像**与 mock 负载生成所需的形态参数。量化锚点、加权导出量与适用区间复核一律落在 `parameters.md`（锚点 A6 及 §8 校准记录）。

---

## 1. 类型一览

| 类型 | `TaskKind` | 典型用途 |
|------|------------|----------|
| AIGC 图像生成 | `aigc_image` | 单帧/少帧图像合成 |
| AIGC 视频生成 | `aigc_video` | 长耗时、大容量视频合成 |
| Agent 请求 | `agent` | 工具调用 / 多步推理，强互动与高频文本增量 |

类型仅作为 `TaskSpec` 数据字段，以及 per-type 执行时长上界覆盖（`parameters.md` §5.3）。提交、领取、生命周期、观测等核心路径**不得**按类型分支。

---

## 2. 分类型画像

### 2.1 AIGC 图像（`aigc_image`）

| 维度 | 画像 |
|------|------|
| 执行时长 | 秒~分钟级，三类中最短 |
| 容量需求 | 小；单设备可较高并发 |
| 输出事件 | 低（进度为主） |
| 产物 | 中等文件，走独立产物通道 |
| 追加指令 / 互动 | 弱 |
| 执行上界覆盖 | 显著小于默认 4h（见 parameters §5.3 / §6） |

### 2.2 AIGC 视频（`aigc_video`）

| 维度 | 画像 |
|------|------|
| 执行时长 | 分钟~小时级，三类中最长 |
| 容量需求 | **大**，可能接近单设备满容量；单设备并发常为 1 |
| 输出事件 | 低（进度为主） |
| 产物 | **大文件**，可能逼近/突破既有产物上界，须走独立通道并监控 OR-6 |
| 追加指令 / 互动 | 弱 |
| 执行上界覆盖 | 接近默认 4h |

### 2.3 Agent 请求（`agent`）

| 维度 | 画像 |
|------|------|
| 执行时长 | 秒~十分钟级 |
| 容量需求 | 小；单设备中~高并发 |
| 输出事件 | **高**（文本增量流；是聚合输出事件速率的主要贡献来源之一） |
| 产物 | 小，可内联 |
| 追加指令 / 互动 | **强**（FR-12 / FR-13 的主要场景） |
| 执行上界覆盖 | 中等（默认与 per-type 覆盖见 parameters） |

## 4. Mock 负载生成参数（验证用）

供 `nova-testkit` / `nova-mock-worker` 使用；具体采样分布以实现为准，须与 §2 画像同向。

| 类型 | 可注入行为 | 输出形态 |
|------|------------|----------|
| `aigc_image` | 慢、卡死、假死、谎报容量 | 稀疏进度事件 + 中等产物句柄 |
| `aigc_video` | 同上；强调长执行与大容量占用 | 稀疏进度 + 大产物句柄 |
| `agent` | 同上；强调追加指令与互动 | 高频文本增量事件 |

---

## 5. 不做什么

- 不为类型新增提交/领取/状态机分支
- 不在匹配器内写死 `if kind == ...`；类型约束若需要，通过 DSL 与 `TaskSpec` 字段表达
- 不把本画像当作容量规划的独立锚点（锚点只有 parameters §2）
