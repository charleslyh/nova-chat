# 设计不变量

> 版本：v2.0
> 依据：[`spec.md`](../requirements/spec.md) · [`decisions.md`](./decisions.md) D19 / D18 / D11
> 违反任一条即某条 CR 不成立。

---

## 0. 判据

若某个设计取值会让系统**不正确**（而非只是变慢），则它是不变量，不是配置项。

---

## 1. Turn 领取与 attempt fence

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-1** | **Turn 领取必须是单点条件更新**（判定与置已领在同一原子操作） | CR-1 | 双领 |
| **INV-2** | **Turn 提交幂等闸门无 TTL 窗口**：存在即拒绝 | CR-2 | 窗口外重放产生第二 Turn |
| **INV-5** | **attempt 严格单调递增，永不重置** | CR-3, CR-7 | 无法识别失效持有者 |
| **INV-6** | **Agent 写入必须携带 `(turn_id, attempt)`，服务端校验为当前值** | CR-3, CR-7 | 僵尸写入污染流 |
| **INV-35** | **每个非终态有超时出口**（pending / claimed / running） | CR-6 | Turn 永久停滞 |

> 原 INV-3/4/7–9/17–24（容量账本、匹配器）随任务系统一并废止（D19）。

## 2. 观测与流式输出

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-10** | **attempt/fence 绑定在 Turn**；观测游标身份是 **Session** | CR-3, FR-11 | 交织或无法跨 Turn 续订 |
| **INV-11** | **全序号由单点分配**（per-session） | CR-5 | 观测者因果顺序相反 |
| **INV-12** | **客户端唯一连接级状态是 `(session_id, last_seq)`**；服务端无连接粘性/连接级游标 | FR-11, FR-12, FR-17 | sticky；换设备无法续订 |
| **INV-13** | **一切重建起点须记录序号**（快照、归档均带 seq） | CR-4, FR-9 | 增量起点不确定 |
| **INV-14** | **热层无请求序号时必须明确报错**，导向快照/冷层；有效 Session 始终可恢复 | CR-4, FR-13, FR-14 | 静默缺口或历史不可开 |
| **INV-15** | **快照序号严格单调**；回退写入丢弃 | CR-4 | 重复投递 |
| **INV-16** | **可合并与不可合并事件显式区分** | CR-4 | 慢客户端丢关键事件 |

### 用语

| 词 | 含义 |
|----|------|
| 连接会话 | TCP/SSE 连接 —— **禁止**作真相 |
| Session | 对话线程 —— **允许且必需** |

## 3. 路径与过载

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-D11** | **meta 与 stream 分承载**（见 D11） | parameters 数量级 | CAS 与 append 互相拖死 |
| **INV-29** | **过载须拒绝新提交，不得无界积压** | FR-18, CR-8 | 等待失控 |
| **INV-30** | **拒绝时不得进入不一致状态** | CR-8 | 过载损坏 |
| **INV-32** | **只读降级时拒绝上行写** | CR-5 | 破坏全序 |
| **INV-33** | **重连须带抖动的指数退避** | OR-1 | 连接风暴 |
| **INV-34** | **持久化先于成功响应** | CR-6 | 返回成功但 Turn 不存在 |

---

## 4. 不可抽象清单

| 项 | 若可配置 |
|----|---------|
| per-session 序号单点分配（INV-11） | 因果顺序破坏 |
| 幂等「存在即拒绝」（INV-2） | 重复 Turn |
| attempt 单调（INV-5） | fence 失效 |
| 客户端游标协议（INV-12） | sticky |
| 快照序号单调（INV-15） | 静默丢事件 |
| meta/stream 分离（D11） | 吞吐与一致性互毁 |

---

## 5. 可替换

| 项 | 约束 |
|----|------|
| stream / snapshot 产品选型 | D14；契约不变 |
| TextDelta 聚合窗口 | 配置项 |
| POST+SSE 是否分 Deployment | D19：一期合并；实测可拆 |
| Agent 实现 | 须遵守 claim + fence + fence |

## 6. 验收对应

| 组 | 手段 |
|----|------|
| 领取与 fence | 并发 claim + 强杀 Agent |
| 流式 | 随机断连比对 + 中途开屏 |
| 过载 | 高压拒绝 + 一致性 |
| 终结性 | 非终态出口审查 |
