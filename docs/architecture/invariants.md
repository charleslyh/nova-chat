# 设计不变量

> 版本：v3.0
> 依据：[`spec.md`](../requirements/spec.md) v3 · [`decisions.md`](./decisions.md) D20 / D21 / D22 / D11
> 违反任一条即某条 CR 不成立。

---

## 0. 判据

若某个设计取值会让系统**不正确**（而非只是变慢），则它是不变量，不是配置项。

---

## 1. 生成领取与 attempt fence

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-1** | **生成领取必须是单点条件更新**（判定与置已领在同一原子操作） | CR-1 | 双领 |
| **INV-2** | **创建幂等闸门无 TTL 窗口**：存在即拒绝 | CR-2 | 窗口外重放产生第二个生成 |
| **INV-5** | **attempt 严格单调递增，永不重置** | CR-3, CR-7 | 无法识别失效持有者 |
| **INV-6** | **执行端写入必须携带 `(response_id, attempt)`，服务端校验为当前值** | CR-3, CR-7 | 僵尸写入污染事件流 |
| **INV-35** | **每个非终态有超时出口**（待领取 / 已领取 / 执行中） | CR-6 | 生成永久停滞 |
| **INV-45** | **失联的执行必被显式判定**：心跳超时或执行 deadline 过期后，reap 抬 fence 并置失败 | CR-6, FR-35 | 生成挂起无人收口，客户端长时间无响应 |
| **INV-51** | **中途作废必须记录该 attempt 的部分用量** | CR-11, FR-36 | token 已消耗但无记录，计费对不上账 |

> 原 INV-3/4/7–9/17–24（容量账本、匹配器）随任务系统一并废止（D19）。

## 2. 事件流与订阅

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-11** | **序号 per-response 0 基连续**：同一次生成内事件序号恰为 `0..n`，无跳号、无重号 | CR-5, CR-4 | `starting_after=N` 无法断定 `N+1` 是下一条，续订语义失效 |
| **INV-12** | **订阅游标是 `(response_id, sequence_number)`**；服务端无连接粘性、无连接级游标 | FR-10, FR-11, FR-32 | sticky；换连接无法续订 |
| **INV-16** | **可合并与不可合并事件显式区分**（仅增量可合并） | CR-4 | 慢订阅者丢关键信封事件 |
| **INV-40** | **在途缓冲有界，且位点不可用时必须显式报错且无恢复路径**：位点低于已驱逐水位或超出保留窗口即返回过期错误，**不返回部分数据、不从其它位点续发、不导向任何回溯层** | CR-4, CR-10, FR-12, SR-4 | 静默从可读到的最早位点续发 ⇒ 内容缺口无法察觉 |
| **INV-48** | **输出条目不由事件流回放派生**：执行端在终态直接提交规范化输出条目；存储内容与事件流是彼此独立的写入路径 | FR-20, D20 ⑦ | 事件日志被迫成为持久化真相源，INV-40 的有界性与整个存储边界失守 |

### 用语

| 词 | 含义 |
|----|------|
| 连接 | TCP/SSE 连接 —— **禁止**作真相 |
| 生成 | 领域资源 —— **允许且必需** |
| 会话线程 | **不是本服务的资源**；无锁、无序号命名空间、无订阅范围 |

> **INV-10 / INV-13 / INV-14 / INV-15 已废止（D20）**：attempt 与游标身份的分离（INV-10）随会话资源取消而消失——两者现在同为生成标识；重建起点记录序号（INV-13）、热层缺口导向快照或冷层（INV-14）、快照序号单调（INV-15）随开屏快照与热冷分层一并删除。**位点不可用的处置由 INV-40 接管，语义从「导向恢复路径」改为「显式失败且无恢复路径」。**

## 3. 上下文与存储

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-41** | **链解析必须有界**：深度与累计字节均设上限，**超限报错而非截断** | CR-9, FR-17 | 上下文被无声裁掉，输出质量下降且不可复现；或单次请求拖垮存储 |
| **INV-42** | **快照固化时校验租户**：创建时解析 `previous` 即校验租户，跨租户即拒——故快照中不可能出现跨租户段 | CR-9, SEC-2, SEC-3 | 跨租户历史泄露 |
| **INV-43** | **内容不静默丢失**：容量触顶、前驱缺失或未开启存储、存储不可用一律在**创建时**显式拒绝 | CR-10, FR-18, FR-37 | 本次看似成功，故障推迟到无关的后续请求，最难排查 |
| **INV-46** | **上下文库不可用时拒绝写入**，绝不降级为静默不存 | CR-10, FR-37, OR-2 | 快照固化不完整，后续轮次缺失历史 |
| **INV-49** | **指令不参与快照**：快照结果只含条目，绝不包含任何环的指令字段 | FR-19 | 调用方换了系统提示却仍受旧指令影响 |
| **INV-44** | **内容完整性可校验，且校验密钥仅来自环境变量**；启用校验但密钥缺失时**启动即失败** | CR-13, FR-39, SEC-4 | 存储层篡改无声生效；或密钥随配置文件泄露 |
| **INV-34** | **持久化先于成功响应** | CR-6 | 返回成功但生成不存在 |

## 4. 协议契约

| # | 不变量 | 支撑需求 | 违反后果 |
|---|--------|---------|---------|
| **INV-50** | **协议子集封闭**：未知字段与子集外的条目类型、内容片段一律拒绝，不静默忽略、不兜底透传 | FR-24, FR-25, FR-26 | 参数写错却静默生效默认值；未知类型成为攻击面 |
| **INV-47** | **链闭合性**：输出条目类型集合 ⊆ 可接受的输入条目类型集合 | CR-12, FR-28 | 自家输出无法作为下一轮输入，上下文链断裂 |
| **INV-52** | **条目引用类型一律拒绝** | SEC-3, FR-25 | 可按标识引用任意历史条目，绕过 INV-42 的逐环校验 |

## 6. 不可抽象清单

| 项 | 若可配置 |
|----|---------|
| 序号 0 基连续（INV-11） | 续订语义失效 |
| 幂等「存在即拒绝」（INV-2） | 重复生成 |
| attempt 单调（INV-5） | fence 失效 |
| 订阅游标协议（INV-12） | sticky |
| 位点过期显式失败（INV-40） | 静默缺口 |
| 输出不由回放派生（INV-48） | 存储边界失守 |
| 快照固化时校验租户（INV-42） | 跨租户泄露 |
| 指令不参与快照（INV-49） | 系统提示语义错乱 |
| 链闭合性（INV-47） | 自伤式链断裂 |
| 高频/低频分承载（D11） | 吞吐与一致性互毁 |

## 7. 可替换

| 项 | 约束 |
|----|------|
| 上下文库 / 账本产品选型 | D14；端口契约不变 |
| 在途缓冲承载（内存 ↔ 共享中间件） | D21 触发条件；`ResponseEventLog` 端口形状不变 |
| 增量事件聚合窗口 | 配置项 |
| 保留期、是否校验完整性、清理节奏 | 配置项（OR-5） |
| ~~链亲和路由~~ | **已移除（D25）**：存储共享化后无节点间转发、无链亲和 |
| 执行端实现 | 须遵守领取 + fence + 终态提交规范化输出 |

## 8. 验收对应

| 组 | 手段 |
|----|------|
| 领取与 fence | 并发领取 + 强杀执行端 |
| 事件流 | 随机断连比对 + 序号连续性强断言 + 位点过期 |
| 上下文链 | 多轮快照拼接 + 超限 + 创建时断裂检查 + 记录级删除 + 跨租户 + 指令不继承 |
| 协议子集 | 未知字段 / 条目引用 / 内联二进制 / 内网链接注入 |
| 链闭合性 | 输出条目回灌为输入 |
| 可靠性 | 优雅停机 + 启动孤儿收口 + 部分用量 + 库不可用 |
| 完整性 | 篡改存储内容后读取 |
| 过载 | 高压拒绝 + 一致性 |
| 终结性 | 非终态出口审查 |
