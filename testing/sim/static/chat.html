What to watch. The request body never grows: turn 5 sends the same amount as turn 1. The client keeps exactly one identifier, which is the whole point of server-side context retrieval.

Reconnects. If the stream drops, it resumes with starting_after=<cursor> — an exclusive cursor, so nothing is replayed and nothing is skipped. If the position has already been evicted the server answers 410 rather than silently resuming from somewhere else; there is deliberately no recovery path for a transient buffer.
